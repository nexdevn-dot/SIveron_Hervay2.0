# Features and workflow

## Workspace areas

| Area | Purpose |
| --- | --- |
| Today | Company/contact counts, activity and next actions |
| Discover | Search by keywords, location and radius; choose sources, preview and run bounded research |
| Signals and audiences | Explicitly activate criteria; review observations and match/no match/unknown classifications |
| Companies | Filter records, save views, inspect profiles and sources, research public emails and review field suggestions |
| Contacts | Research decision-makers and email evidence; explicitly adopt reviewed findings; manage notes, blocks and trash |
| Company reports | Create source-linked reports from stored signals, with open checks, Markdown and print/PDF output |
| AI assistant | Optional search suggestions, usage guidance and analysis of supported stored-data queries |
| Campaigns | Compose drafts with rich text, placeholders, attachments, follow-ups and reusable templates |
| Outbox | Review messages, explicitly approve and inspect readiness or blocking reasons |
| Conversations and sales | Review replies, record outcomes, manage explicit opportunities and next tasks |
| Settings and help | Configure integrations, usage, agent controls and German/English help |

## Typical path

1. Choose the signals relevant to your own use case.
2. Preview and run a company search with suitable sources and limits.
3. Filter and review companies and their evidence.
4. Research contacts and explicitly adopt selected findings.
5. Optionally create company reports from stored observations.
6. Draft a campaign, preview it and prepare its messages.
7. Review the outbox and approve messages explicitly when live operation is configured.
8. Review replies and record outcomes and next tasks.

This is a description of the workflow, not a setup instruction to start outreach.
Development defaults keep sending disabled and paused.

## Evidence and control

Unknown is distinct from no match. Missing evidence does not prove an attribute
is absent. Discovered addresses are not automatically verified. Provider coverage,
website access, rate limits and CAPTCHAs may limit findings.

Accepting an assistant search proposal populates search criteria; it does not
start research. A report summarizes stored evidence rather than running a fresh
comprehensive website audit. Approval, suppression and delivery gates remain explicit.

## Source and budget choices

[Low-cost lead research](Low-cost-lead-research) compares free/local discovery,
paid data and selective contact enrichment. Its detailed repository guide contains
dated provider references, imported fields, integration restrictions and practical
budget approaches. A source offering a paid plan does not mean the current adapter
supports that plan. Keep research, evidence review, adoption and outreach separate.
